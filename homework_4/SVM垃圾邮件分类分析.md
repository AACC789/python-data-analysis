# 基于支持向量机的 Spambase 垃圾邮件分类分析

## 一、实验目的与课件对应关系

本实验参考《04_SVM_Detail.html》中“案例①：垃圾邮件分类”，使用支持向量机（Support Vector Machine，SVM）区分正常邮件和垃圾邮件。课件明确给出了 Spambase 数据集，并推荐线性核与 RBF 核。本实验使用同名真实数据集，完成数据检查、清洗、特征标准化、模型训练、参数选择与分类评估。

实验的核心问题是：邮件的词频、符号频率和连续大写字母特征，能否有效区分垃圾邮件？在统一的数据划分与预处理下，两种核函数的分类效果有何差异？

## 二、数据集来源与字段说明

数据来自 UCI Machine Learning Repository，属于题目允许的“其它网站”，无需 Kaggle 账号或 API 密钥。

- 官方介绍：https://archive.ics.uci.edu/dataset/94/spambase
- 官方下载：https://archive.ics.uci.edu/static/public/94/spambase.zip
- 数据 DOI：https://doi.org/10.24432/C53G6X
- 数据文件：`data/spambase.data`，无表头，最后一列为分类标签。
- 授权：CC BY 4.0；来源为 Hopkins、Reeber、Forman 和 Suermondt 于 1999 年提供的 Spambase 数据。

| 项目 | 内容 |
| --- | --- |
| 原始样本数 | 4601 封邮件 |
| 输入特征数 | 57 |
| 正常邮件 | 2788 封，标签 0 |
| 垃圾邮件 | 1813 封，标签 1 |
| 缺失值数量 | 0 |
| 分类任务 | 二分类，以垃圾邮件为正类 |

57 个特征由三部分构成：48 个单词频率特征、6 个字符频率特征，以及 3 个连续大写字母长度统计特征。单词和字符频率按百分比表示；大写字母特征分别为连续大写字母的平均长度、最大长度和大写字母总数。因此，各列数值尺度并不相同，需要标准化。

数据已经转换为数值特征，并非原始邮件正文，本实验不再额外分词或计算 TF-IDF。直接套用文本向量化会改变课件中的数据表示。

## 三、算法原理

### 3.1 最大间隔与软间隔

SVM 寻找一个决策边界，使两类样本在边界附近尽可能留出较宽间隔。距离边界较近、对边界位置有决定作用的训练样本称为支持向量。由于真实邮件特征存在重叠，本实验使用允许部分误分类的软间隔 SVM。

其优化目标可写为：`min 1/2 × ||w||² + C × Σξᵢ`，约束为 `yᵢ(wᵀφ(xᵢ)+b) ≥ 1−ξᵢ` 且 `ξᵢ ≥ 0`。这里理论标签为 −1/+1，代码中使用 0/1，由 scikit-learn 内部处理。

参数 C 控制间隔与训练误差之间的权衡。C 较小，允许更多训练误差；C 较大，对误分类处罚更强，也可能提高过拟合风险。

### 3.2 线性核与 RBF 核

线性核为 `K(x,z)=xᵀz`，用于构造线性决策边界。RBF 核为 `K(x,z)=exp(−γ||x−z||²)`，可以形成非线性边界。γ 决定单个样本影响范围：过大会使边界更局部、复杂，过小则可能欠拟合。

本实验通过训练集内部交叉验证选择 C 与 γ，而不预先断定复杂核函数一定更好。SVM 本身也不保证优于所有其它分类算法。

## 四、数据处理与实验设计

### 4.1 数据质量检查

首先验证数据共有 58 列、标签仅为 0 或 1，并检查缺失值及无穷值。原始数据中有 391 条完全重复记录（不计各组首次出现的记录）。为避免相同特征样本跨训练集与测试集，先按全部特征检查标签冲突，移除相同特征却标签不同的全部记录 6 条，再删除剩余的完全重复记录 391 条。

最终保留 4204 条记录，其中正常邮件 2528 条，垃圾邮件 1676 条。这一策略得到的是清洗后、标签一致的唯一特征样本评价；移除矛盾样本可能降低任务难度，因此结果不能直接解释为原始全部邮件上的线上效果。

### 4.2 训练测试划分与标准化

采用分层随机抽样，训练集约占 80%，测试集约占 20%，随机种子固定为 42。训练集有 3363 条，测试集有 841 条，具体样本数由分割函数取整确定。分层抽样有助于保留两类样本比例。

标准化公式为 `z=(x−μ)/σ`。使用 `Pipeline(StandardScaler, SVC)`，每次交叉验证均只用当前训练折计算均值和标准差，随后转换验证折。最终模型也只使用完整训练集拟合标准化参数，测试集不参与拟合与选参。

### 4.3 参数搜索与选择规则

| 模型 | C 候选值 | gamma 候选值 |
| --- | --- | --- |
| 线性核 SVM | 0.1、1、10 | 不适用 |
| RBF 核 SVM | 0.1、1、10 | scale、0.001、0.01、0.1 |

总计 15 组候选参数，每组进行 5 折分层交叉验证，共 75 次候选拟合。使用垃圾邮件类别的平均 F1 作为选参依据，同时记录验证准确率和 ROC-AUC。`scale` 表示由当前拟合数据的特征数与方差计算 γ。

最终模型在测试前已经由训练集交叉验证确定。为比较核函数，还分别报告各核函数在训练集内部选出的最佳候选的测试指标；不会再根据测试集表现改变最终选择。另设置“全部预测为正常邮件”的多数类基线，用于判断模型是否学到了有意义的区分规则。

## 五、评价指标

准确率表示全部邮件中预测正确的比例；精确率表示被判为垃圾邮件的邮件中实际垃圾邮件的比例；召回率表示实际垃圾邮件中被检出的比例。F1 是精确率与召回率的调和平均。ROC-AUC 衡量模型在不同阈值下对两类的排序区分能力，本实验直接使用 `decision_function` 分数计算，分数并非概率。

邮件过滤还需要关注正常邮件被误拦截，以及垃圾邮件漏检两种错误。只看准确率容易忽略具体错误代价，因此同时报告 F1、ROC-AUC 和混淆矩阵。

## 六、实际运行结果

下列数据由本次实验实际运行得到，并非直接抄用课件示例。交叉验证 F1 的“±”为五折分数的标准差，不是置信区间。

| 模型 | 训练集 CV F1 | 测试准确率 | 垃圾邮件精确率 | 垃圾邮件召回率 | 垃圾邮件 F1 | ROC-AUC |
| --- | --- | --- | --- | --- | --- | --- |
| 多数类基线 | — | 0.6017 | 0.0000 | 0.0000 | 0.0000 | 0.5000 |
| 线性核 SVM | 0.9058 ± 0.0106 | 0.9239 | 0.9094 | 0.8985 | 0.9039 | 0.9715 |
| RBF 核 SVM | 0.9070 ± 0.0088 | 0.9334 | 0.9164 | 0.9164 | 0.9164 | 0.9798 |

训练集交叉验证选出的最终参数为：`{"svm__C": 10, "svm__gamma": 0.01, "svm__kernel": "rbf"}`，平均 F1 为 0.9070。其测试准确率为 93.34%，垃圾邮件 F1 为 0.9164，ROC-AUC 为 0.9798。

### 6.1 混淆矩阵与错误分析

| 真实类别 / 预测类别 | 预测正常邮件 | 预测垃圾邮件 |
| --- | --- | --- |
| 正常邮件（0） | 478 | 28 |
| 垃圾邮件（1） | 28 | 307 |

模型正确放行了 478 封正常邮件，正确识别了 307 封垃圾邮件；28 封正常邮件被误判为垃圾邮件，28 封垃圾邮件被漏检。前一种错误可能造成重要邮件被拦截，后一种错误则会让垃圾邮件进入收件箱。实际部署可基于独立验证集调整决策阈值，以适应不同误判成本。

最终模型在正常邮件与垃圾邮件两类上分别有 394、374 个支持向量。支持向量是模型边界的关键样本，其数量本身不能直接证明模型的泛化水平。

### 6.2 各类别分类效果

| 类别 | 精确率 | 召回率 | F1 | 测试样本数 |
| --- | --- | --- | --- | --- |
| 正常邮件 | 0.9447 | 0.9447 | 0.9447 | 506 |
| 垃圾邮件 | 0.9164 | 0.9164 | 0.9164 | 335 |
| 宏平均 | 0.9305 | 0.9305 | 0.9305 | 841 |
| 加权平均 | 0.9334 | 0.9334 | 0.9334 | 841 |

模型对正常邮件的 F1 高于垃圾邮件，说明两类邮件的识别效果仍有差异。宏平均对两个类别赋予相同权重，加权平均按各类别测试样本数量计算。

### 6.3 类别分布与模型效果对照

清洗后的样本类别分布如下：

| 邮件类别 | 样本数量 | 占比 |
| --- | --- | --- |
| 正常邮件 | 2528 | 60.13% |
| 垃圾邮件 | 1676 | 39.87% |
| 合计 | 4204 | 100.00% |

两类样本存在一定数量差异，但垃圾邮件仍占约四成，因此本实验同时报告准确率、精确率、召回率和 F1，避免仅根据总体准确率作出判断。

RBF 核的测试准确率为 93.34%，高于线性核的 92.39%，相差约 0.95 个百分点；垃圾邮件 F1 从 0.9039 提高至 0.9164。RBF 核与线性核的 ROC-AUC 分别为 0.9798 和 0.9715，表明两者均具有较好的排序区分能力，本次划分中 RBF 核表现略好。不过，两种模型的交叉验证平均 F1 接近，不能仅凭一次划分认定这种优势具有统计显著性。

## 七、结果讨论与局限

从本次结果可以判断，邮件统计特征具有分类信息，SVM 相比多数类基线能够识别出较大部分垃圾邮件。两种核函数的差异应结合表中的 F1 与 AUC 分析：F1 反映默认决策阈值下的效果，AUC 反映整体排序能力，两个指标的优劣排序不一定相同。

与课件示例数值存在差异是正常现象。课件未明确给出完整清洗规则、随机划分和软件版本；本实验处理了重复与标签冲突，并依据交叉验证选参。因此不将课件中的准确率或训练耗时当作必须复现的结论，也不据此宣称算法必然优于逻辑回归。

本实验采用一次固定随机划分，交叉验证只覆盖训练集；测试结果仍可能受样本划分影响。数据来自较早期的邮件集合，包含特定收件人或组织相关的词频线索，对现代邮件以及其它用户的泛化能力需要额外验证。相同特征去重能减少直接重复造成的泄漏，但无法排除近重复邮件、同源邮件等其它相关性。

未来可加入较新的外部测试集，按时间或来源划分数据，并在训练集内部比较特征筛选、类别权重与阈值调整。有关优化必须在验证阶段完成，不能反复查看同一测试集后继续调参。

## 八、实验结论

本实验完成了课件 Spambase 案例对应的 SVM 分类流程，包括官方数据获取、数据质量检查、重复样本处理、分层划分、标准化、两种核函数的参数搜索及测试评价。训练集交叉验证选择的模型在独立测试集上取得 93.34% 的准确率和 0.9164 的垃圾邮件 F1，说明 SVM 能够利用该数据集中的统计特征完成有效的邮件二分类。
